🎓 Academic Performance Planner

A C-based mini project designed to help students calculate their CGPA and predict the required SGPA to achieve future academic goals.

📌 Problem Statement

Students often struggle to:

Track their CGPA accurately
Set realistic academic targets
Understand what SGPA is required in upcoming semesters
🚀 Solution

This project provides a simple system that:

Automates CGPA calculation
Predicts required SGPA for target CGPA
Sets measurable academic targets
Enables goal-oriented planning
✨ Features
🔹 CGPA Calculator
Takes SGPA and credit inputs
Uses loop-based computation
Outputs final CGPA
🔹 SGPA Predictor
Accepts target CGPA
Applies formula-based logic
Displays required SGPA range
